Ingeniería agéntica

Un agente sin spec ni verificación solo genera deuda más rápido

Uso Cursor, Kiro y Claude Code con el mismo loop: spec con criterios de aceptación, plan, tareas acotadas para el agente, tests y revisión humana antes del merge. El resultado depende menos del prompt que del context engineering y del harness: qué contexto recibe el agente, qué tools puede usar y qué lo frena cuando se equivoca. Todavía lo estoy aprendiendo. Mi apuesta para los equipos: menos tiempo escribiendo cada línea, más tiempo diseñando specs, contexto y evals.

Cómo lidero

Cuatro principios que llevo a cada equipo

Contexto antes que microgestión

Un equipo decide bien cuando entiende el problema y sus restricciones. Mi trabajo es crear ese contexto, no tomar cada decisión.

Equipos que no dependen de héroes

Si algo funciona solo cuando una persona está presente, todavía no está resuelto. Busco conocimiento compartido y delivery sostenible.

La arquitectura acompaña al negocio

Multi-tenancy, doble moneda o un ledger de eventos son decisiones de negocio que se escriben en código y se pagan caro si llegan tarde.

La IA amplifica, no sustituye el criterio

Acelera investigar, especificar y construir. Decidir qué se construye, revisar lo que produce y hacerse cargo del resultado sigue siendo de las personas.
